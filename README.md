> ### АНТИВИРУСНАЯ ПРОВЕРКА

> WinDivert способен вызвать срабатывание антивируса.  
> Это средство перехвата и фильтрации трафика, без которого zapret не работает.
> WinDivert может применяться как безопасными, так и вредоносными программами, однако сам по себе вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как инструменты повышенного риска или хакерские средства, после чего удаляет их и помещает в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA — потенциально нежелательных приложений. Например, Kaspersky предлагает параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При точной настройке исключений предпочтительно добавить исключение; если вы не уверены в своих действиях, рекомендуется отключить обнаружение PUA.

## ⚙️ Использование

1. Сначала включите безопасный DNS (Secure DNS).
   * В Chrome включите "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию".
   * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
   * Windows 11 позволяет активировать Secure DNS непосредственно в настройках ОС — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот способ рекомендуется.
   * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/BrawlerStudio/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг не нужен.

4. Распакуйте файлы в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите нужный файл.
   * Для поиска рабочей стратегии откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
   * Чтобы включить автозапуск, выберите **`service.bat`** → `Install Service` → нужную стратегию.

## ℹ️ Кратко о файлах и командах

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки вариантов. Результат зависит от множества факторов, поэтому **перебирайте разные стратегии — ALT, FAKE и другие — пока не найдёте подходящую**.

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — установить выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб.
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию в автозапуске и WinDivert.
  - **`Game Filter`** — изменить режим обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию необходимо перезапустить.**  
  Значение в скобках показывает, включён ли режим.
  - **`IPSet Filter`** — выбрать режим обработки сервисов из `ipset-all.txt`. Это полезно при проверке ресурса, который без zapret открывается, а с ним — нет.  
  Текущее состояние отображается в скобках:
    - `none` — IP-адреса не проверяются;
    - `loaded` — IP проверяется на наличие в списке;
    - `any` — под фильтр попадает любой IP.
  - **`Auto-Update Check`** — включить или отключить автоматическую проверку обновлений.
  - **`Replace active fakes`** — заменить используемый fake другим файлом из каталога `bin`.
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновить hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений.
  - **`Run Diagnostics`** — проверить распространённые причины неисправности zapret.  
  В конце диагностики можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапных сбоях.
  - **`Run Tests`** — открыть инструмент проверки стратегий:
    - `Standard tests` — проверка сайтов из `utils/targets.txt`;
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и неисправности

### После запуска `general*` ничего не видно

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться `winws.exe`. Его можно заметить на панели задач.  
Если процесс не запустился, обратитесь к [#522](https://github.com/BrawlerStudio/zapret-discord-youtube/issues/522).

### Не подходит ни одна стратегия

- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере

В **`service.bat`** выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - скопируйте весь текст из открытого Блокнота;
  - откройте файл `hosts` в появившейся папке текстовым редактором, запущенным от имени администратора;
  - добавьте скопированный текст в конец `hosts` либо замените ранее добавленный аналогичный блок;
  - сохраните файл и проверьте подключение. Если результата нет, убедитесь, что изменения действительно записались.

#### Работа не гарантируется. При отсутствии результата используйте [версию Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/BrawlerStudio/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем переставать работать.**
> Отдельный вариант способен некоторое время работать, а затем перестать из-за обнаружения используемого метода.
> В репозитории есть множество стратегий. Если готовые варианты не помогают, создайте новую стратегию на основе одной из них и измените её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` откройте `Run Diagnostics` и проверьте, нет ли ошибок.
- Убедитесь, что адрес нужного ресурса присутствует в списках доменов или IP.
- Проверьте другие варианты, в том числе **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- Дополнительная информация есть в [#765](https://github.com/BrawlerStudio/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить проект?

- Сохраните ресурсы и данные, которые добавляли самостоятельно.
- Перезапустите устройство.
- Выполните `service.bat` → `Remove Services`.
- Запустите `service.bat` → `Run Diagnostics`; исправьте найденные ошибки и в конце подтвердите действие клавишей Y.
- Удалите старую папку zapret.
- Скачайте свежую версию со [страницы релизов](https://github.com/BrawlerStudio/zapret-discord-youtube/releases) — архив `zapret-discord-youtube-...`.
- Нажмите правой кнопкой по архиву и откройте свойства. Если внизу справа есть "Разблокировать", включите его, нажмите "Применить" и затем "ОК".
- Распакуйте архив в новую папку в корне диска; путь не должен содержать пробелы и специальные символы.
- Запускайте разные `general`-скрипты и проверяйте доступ к интернет-ресурсам. Если вариант не работает, закройте программу через значок замка на панели задач и выберите другую стратегию.
- После выбора рабочего варианта включите автозапуск через `service.bat` → `Install Service` → нужная стратегия.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Инструкция доступна [здесь](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть в службах

1. Узнайте имя службы в командной строке Windows, открыв её через Win+R → `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8F-использование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если прежняя недавно перестала работать.
- См. также [#251](https://github.com/BrawlerStudio/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8F-использование).
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- В `service.bat` перейдите в `Run Diagnostics` и очистите кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ею.
- Если Discord не открывается и в браузере, снова проверьте остальные стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/BrawlerStudio/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/BrawlerStudio/tg-ws-proxy).
- Либо используйте бесплатные MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Универсальная последовательность действий:
- обновите ipset через `service.bat` и включите `Game Filter`;
- если этого недостаточно, дополнительно включите `ipset any`.

У `ipset any` есть побочный эффект: многие сайты могут перестать открываться. Не оставляйте этот режим включённым постоянно. Найдите IP-адреса, используемые игрой, и добавьте их в `ipset-all.txt`.

Если проблема сохранилась, создайте обсуждение в разделе [Discussions](https://github.com/BrawlerStudio/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли подходящего ответа

- Опишите проблему [здесь](https://github.com/BrawlerStudio/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Дополнительные адреса можно указать в следующих файлах:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены-исключения, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — исключаемые IP-адреса и подсети.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
